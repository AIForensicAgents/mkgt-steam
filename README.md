## 📖 Overview

**MKGT-STEAM** is a creative campaign by [AIForensicAgents](https://github.com/AIForensicAgents) that draws powerful visual and conceptual parallels between the catastrophic failures of the steamboat era (1800s) and the emerging risks of modern artificial intelligence.

Through a curated series of compelling images, ad copy, and a dedicated landing page, this project asks a provocative question:

> *What if the lessons we failed to learn from exploding boilers, reckless races, and ignored warning gauges are the same lessons we're failing to learn from AI meltdowns, arms races, and bias alerts?*

This repository serves as both a **STEAM education resource** and a **marketing campaign toolkit** — bridging Science, Technology, Engineering, Arts, and Mathematics through the lens of historical and technological accountability.

## ✨ Features

- **📸 10 Curated Visual Parallels** — Side-by-side conceptual images connecting steamboat disasters to modern AI failures
- **📝 Campaign Ad Copy** — Ready-to-use marketing language for social media, presentations, and outreach
- **🌍 Interactive Landing Page** — A fully designed HTML page for campaign delivery and engagement
- **📋 Campaign Brief** — Strategic documentation outlining goals, audience, and messaging framework
- **🎓 STEAM-Aligned** — Designed for educators, technologists, and advocates who value interdisciplinary thinking

## 🚀 Getting Started

### Prerequisites

No special tools required — this is a static site project. You just need:

- A modern web browser
- (Optional) A local HTTP server for development

### Quick Start

1. **Clone the repository**

   ```bash
   git clone https://github.com/AIForensicAgents/mkgt-steam.git
   cd mkgt-steam
   ```

2. **Open the landing page locally**

   ```bash
   # Simply open in your browser
   open index.html

   # Or serve locally with Python
   python3 -m http.server 8000
   ```

3. **Explore the campaign materials**

   - Read `CAMPAIGN-BRIEF.md` for strategic context
   - Review `ad-copy.txt` for messaging
   - Browse the `images/` directory for all visual assets
