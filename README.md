# 🚢💥 MKGT-STEAM — When History Repeats in the Machine

**A STEAM Education Campaign by [AIForensicAgents](https://github.com/AIForensicAgents)**

> *The boilers have changed. The recklessness hasn't.*

---

## 📖 Overview

**mkgt-steam** is an interactive STEAM education campaign that draws striking visual and narrative parallels between the catastrophic steamboat disasters of the 19th century and the AI failures unfolding today. Through scroll-driven storytelling, AI-generated artwork, and historically grounded research, this project asks a provocative question:

**What if we've seen all of this before?**

Boiler explosions killed thousands in the 1800s — not because the technology was inherently evil, but because regulation lagged behind innovation, warnings were ignored, and profit was prioritized over people. Today, as AI systems fail, discriminate, and destabilize, the patterns are unmistakable.

This repository contains everything needed to experience, share, and build upon the campaign — from the interactive landing page to the full visual gallery and marketing materials.

## 💡 The Concept

The campaign is built around **10 visual parallels** — each one pairing a real pattern from steamboat-era history with its modern AI equivalent:

| Then (1800s) | Now (2020s) |
|---|---|
| Boiler explosions from ignored maintenance | Server meltdowns from unchecked infrastructure |
| Captains losing control of vessels | Engineers losing control of autonomous AI |
| Reckless steamboat races for prestige | The AI arms race between corporations |
| Ships sinking with hundreds aboard | Societies drowning in AI-generated misinformation |
| Pressure gauges ignored by operators | Bias alerts dismissed by developers |
| Post-wreckage investigations | Post-incident AI audits and forensics |
| Sensational disaster headlines | Modern AI failure headlines |
| Overcrowded boats exploiting passenger trust | Data-hungry platforms exploiting user privacy |
| Mechanical explosions tearing hulls apart | Neural network failures shattering trust |
| Memorials for steamboat victims | Communities harmed by AI seeking recognition |

The throughline is clear: **when innovation outpaces accountability, people get hurt.** The technology changes. The human failures don't.
